# Nath Financial Solutions — Experience Edition V3

A customer-first multilingual financial-services website built with Next.js, TypeScript and Framer Motion.

## What changed in V3

- Complete visual reset from the earlier navy/gold template
- Minimal-copy, animation-led hero experience
- Auto-switching financial-goal preview and interactive tabs
- Call and WhatsApp controls appear only after the hero
- Scroll-reveal storytelling and animated service cards
- Three-step guided enquiry journey instead of a long static form
- Mobile-first interactions and reduced information pressure
- English, Hindi and Marathi routes retained

## Run locally

1. Install Node.js 20 or newer.
2. Open Terminal in this folder.
3. Run `npm install`.
4. Copy `.env.example` to `.env.local`.
5. Run `npm run dev`.
6. Open `http://localhost:3000`.
